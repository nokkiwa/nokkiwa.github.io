[1647번: 도시 분할 계획](https://www.acmicpc.net/problem/1647)

### 어떤 문제인가

집 `N`개가 길로 이어져 있고, 각 길에는 유지비가 붙어 있다.
이 마을을 **두 개의 마을로 나누되**, 각 마을 안의 집들은 서로 연결되어 있어야 하고, 남기는 길들의 유지비 합이 최소가 되게 만드는 문제다.

`N`은 최대 100,000, 길은 최대 1,000,000개다.

<br>

### 왜 최소 스패닝 트리인가

"모든 집을 연결하면서 비용을 최소로"라는 조건이 그대로 **최소 스패닝 트리(MST)** 의 정의다.
여기에 "두 마을로 나눈다"가 붙는데, 이건 생각보다 단순하게 처리된다.

MST를 먼저 완성하면 간선이 `N-1`개인 트리가 된다.
이 트리에서 간선을 하나 끊으면 정확히 **두 덩어리로 갈라진다.** 트리는 사이클이 없어서 어떤 간선을 끊어도 반드시 두 조각이 되기 때문이다.

그러면 남은 건 "어느 간선을 끊을 것인가"인데, 비용을 최소로 하려면 **가장 비싼 간선**을 끊으면 된다.

즉 전체 문제가 `MST 총합 - 가장 큰 간선` 하나로 정리된다.

<br>

### 접근 방식

최소 스패닝 트리를 이용한 문제이다. 문제는 간단하다.
크루스칼 알고리즘을 통해 최소 가중치를 가지는 트리 경로를 구한 후, 이를 다시 정렬하여 가중치가 가장 큰 값을 뺀 값을 출력해주었다.

크루스칼은 이렇게 동작한다.

1. 모든 간선을 가중치 오름차순으로 정렬한다
2. 싼 것부터 하나씩 보면서, **양 끝이 이미 연결되어 있지 않으면** 채택한다
3. 이미 연결되어 있으면 건너뛴다 (넣으면 사이클이 생긴다)

여기서 "이미 연결되어 있는지"를 판단하는 게 유니온 파인드다.

```cpp
int findParent(int a) {
    if (a == p[a]) return a;
    else return p[a] = findParent(p[a]);
}
```

`p[a] = findParent(p[a])`가 **경로 압축(path compression)** 이다.
루트를 찾아 올라가면서 지나온 노드들의 부모를 루트로 바로 갈아끼운다. 이걸 안 하면 트리가 한 줄로 길어져 매 탐색이 O(N)까지 늘어난다.

간선을 채택할 때마다 `road`에 따로 담아뒀다가, 마지막에 정렬해서 가장 큰 것을 빼는 방식으로 마무리했다.

```cpp
sort(road.begin(), road.end());
result -= road.back().first;
```

사실 `v`가 이미 오름차순으로 정렬되어 있으므로 **채택된 마지막 간선이 곧 가장 비싼 간선**이다.
`road`를 다시 정렬하지 않고 마지막에 채택한 값을 기억해 두기만 해도 되는데, 확실하게 하려고 한 번 더 정렬했다.

<br>

### 시간 복잡도

간선 정렬이 **O(M log M)** 으로 지배적이다. M이 최대 1,000,000이니 여기가 전부라고 봐도 된다.
유니온 파인드는 경로 압축을 하면 거의 상수 시간에 가까워서 무시할 수 있다.

간선이 100만 개라 입출력도 부담이 되는데, `ios_base::sync_with_stdio(false)`와 `cin.tie(NULL)`을 걸어두지 않으면 시간 초과가 날 수 있다.

<br>

### 배운 점

어렵지 않게 풀 수 있었다. 다만 **최소 스패닝 트리를 사용한다는 것을 떠올리는 데 시간이 오래 걸렸다.**
주어진 노드들 간의 무언가를 최소로 하는 문제라면 최소 스패닝 트리를 떠올리도록 하자.

"두 개로 나눈다"는 조건이 어렵게 보였는데, MST를 먼저 만들고 나면 **간선 하나를 끊는 문제로 축소된다**는 게 이 문제의 핵심이었다.
비슷하게 세 마을로 나누라고 하면 가장 비싼 간선 두 개를 빼면 된다.

같은 MST 유형으로 [1774 우주신과의 교감](/baekjoon/2026/08/02/백준-1774-우주신과의-교감.html)과 [2887 행성 터널](/baekjoon/2026/08/24/백준-2887-행성-터널.html)도 풀어봤는데, 둘 다 크루스칼 자체보다 **간선을 어떻게 만들어낼 것인가**가 관건이었다.

<br>

---

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int N, M, result = 0;
vector<pair<int, pair<int, int>>> v;
vector<pair<int, pair<int, int>>> road;
int p[100001];

int findParent(int a) {
    if (a == p[a]) return a;
    else return p[a] = findParent(p[a]);
}

void unionParent(int a, int b) {
    a = findParent(a);
    b = findParent(b);

    if (a != b) p[a] = b;
}

bool sameParent(int a, int b) {
    a = findParent(a);
    b = findParent(b);

    if (a == b) return true;
    else return false;
}

void solution() {
    for (int i = 1; i <= N; i++) {
        p[i] = i;
    }

    sort(v.begin(), v.end());

    for (int i = 0; i < v.size(); i++) {
        int a = v[i].second.first;
        int b = v[i].second.second;
        int c = v[i].first;

        if (!sameParent(a, b)) {
            unionParent(a, b);
            road.push_back(v[i]);
            result += c;
        }
    }

    sort(road.begin(), road.end());

    result -= road.back().first;

    cout << result;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL); cout.tie(NULL);

    cin >> N >> M;

    int a, b, c;
    for (int i = 0; i < M; i++) {
        cin >> a >> b >> c;
        v.push_back({ c,{a,b} });
    }

    solution();

    return 0;
}
```
