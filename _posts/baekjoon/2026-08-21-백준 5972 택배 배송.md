[5972번: 택배 배송](https://www.acmicpc.net/problem/5972)

### 어떤 문제인가

헛간 `N`개가 길로 이어져 있고, 각 길에는 지나갈 때 만나는 소의 수가 적혀 있다.
1번 헛간에서 `N`번 헛간까지 가면서 **만나는 소의 총합을 최소로** 하는 문제다.

`N`과 길의 수 `M` 모두 최대 50,000이고, 길은 양방향이다.

<br>

### 왜 다익스트라인가

조건이 딱 세 개다.

- 출발점 하나에서 특정 지점까지의 최단 거리
- 가중치가 **모두 양수**
- 정점과 간선이 각각 5만 개

가중치가 양수이므로 다익스트라가 맞다. 음수가 섞여 있었다면 [11657 타임머신](/baekjoon/2026/08/12/백준-11657-타임머신.html)처럼 벨만 포드를 써야 했을 것이다.

정점 5만 개에 벨만 포드를 쓰면 O(N × M) = 25억이라 시간 초과다. 다익스트라의 O(E log V)가 필요한 규모다.

<br>

### 우선순위 큐를 최소 힙으로 쓰는 법

C++의 `priority_queue`는 기본이 **최대 힙**이다. 다익스트라는 가장 가까운 정점부터 꺼내야 하니 반대다.

`greater`를 넘겨 비교자를 바꿀 수도 있지만, 여기서는 **거리에 음수를 붙여** 넣는 방식을 썼다.

```cpp
pq.push({ -next_cost, next });
...
int cost = -pq.top().first;
```

부호를 뒤집어 넣으면 최대 힙이 알아서 가장 작은 원래 값을 위로 올려준다. 꺼낼 때 다시 뒤집으면 된다.
선언이 짧아져서 자주 쓰는 방법이다.

`pair`의 첫 원소를 거리로 둔 것도 의도적이다. `pair` 비교는 첫 원소를 먼저 보기 때문에, 거리를 앞에 둬야 거리 기준으로 정렬된다.

<br>

### 접근 방식

일반적인 다익스트라 구현 문제다.

먼저 길을 입력받을 때 **양방향이므로 양쪽으로 저장**해준다.

```cpp
v[a].push_back({ b,c });
v[b].push_back({ a,c });
```

이걸 한쪽만 넣으면 답이 틀리는데, 틀린 이유를 찾기가 은근히 어렵다.

시작 지점이 `1`, 도착 지점이 `N`으로 고정이므로 1부터 다익스트라를 돌려 각 지점까지의 최단 거리를 구하고 `d[N]`을 출력했다.

```cpp
if (d[now] < cost) continue;
```

이 한 줄이 성능을 좌우한다.
같은 정점이 큐에 여러 번 들어갈 수 있는데, 이미 더 짧은 경로로 처리된 정점이라면 건너뛴다. 이걸 빼면 불필요한 탐색이 폭증한다.

<br>

### 시간 복잡도

**O(E log V)** 다. 간선 5만 개에 로그가 붙는 수준이라 여유롭다.

<br>

### 배운 점

쉽게 풀 수 있었던 문제였다. 다익스트라를 오랜만에 상기시켜준 좋은 문제였다.

정리해두면 최단 경로에서 무엇을 고를지는 이렇게 갈린다.

| 상황 | 알고리즘 |
|---|---|
| 가중치 양수, 한 지점에서 출발 | 다익스트라 |
| 음수 간선 존재, 음수 사이클 판별 필요 | 벨만 포드 |
| 모든 정점 쌍 간의 최단 거리 | 플로이드 워셜 |
| 가중치가 전부 같음 | BFS |

마지막 경우가 [16948 데스 나이트](/baekjoon/2026/08/23/백준-16948-데스-나이트.html)다. 이동 비용이 전부 1이면 BFS만으로 최단 거리가 나온다.

<br>

---

```cpp
#include <iostream>
#include <queue>
#include <vector>

#define INF 987654321

using namespace std;

int N, M;
int d[50001];
vector<pair<int, int>> v[50001];

void dijkstra() {
    priority_queue <pair<int, int>> pq;

    d[1] = 0;
    pq.push({ 0,1 });

    while (!pq.empty()) {
        int cost = -pq.top().first;
        int now = pq.top().second;

        pq.pop();

        if (d[now] < cost) continue;

        for (int i = 0; i < v[now].size(); i++) {
            int next = v[now][i].first;
            int next_cost = cost + v[now][i].second;

            if (d[next] <= next_cost) continue;

            d[next] = next_cost;
            pq.push({ -next_cost, next });
        }
    }
}

void solution() {
    for (int i = 1; i <= N; i++) {
        d[i] = INF;
    }

    dijkstra();

    cout << d[N];
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL); cout.tie(NULL);

    cin >> N >> M;

    int a, b, c;
    for (int i = 0; i < M; i++) {
        cin >> a >> b >> c;

        v[a].push_back({ b,c });
        v[b].push_back({ a,c });
    }

    solution();

    return 0;
}
```
