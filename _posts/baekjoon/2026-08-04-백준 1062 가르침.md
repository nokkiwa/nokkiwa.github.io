[1062번: 가르침](https://www.acmicpc.net/problem/1062)

### 어떤 문제인가

남극 문자로 된 단어 `N`개가 있는데, 모든 단어는 **`anta`로 시작해서 `tica`로 끝난다.**
알파벳 `K`개만 가르칠 수 있을 때, 학생들이 **읽을 수 있는 단어 수를 최대**로 만드는 문제다.

`N`은 최대 50, `K`는 0 이상 26 이하다.

<br>

### 문제의 절반은 조건에서 풀린다

모든 단어가 `anta`로 시작하고 `tica`로 끝난다는 건, 어떤 단어를 읽든 **`a, n, t, i, c` 다섯 글자는 무조건 알아야 한다**는 뜻이다.

여기서 두 가지가 바로 나온다.

- `K < 5`이면 단어를 하나도 읽을 수 없으므로 **답은 무조건 0**
- `K >= 5`이면 다섯 글자를 미리 배운 것으로 두고, **남은 `K-5`개를 21글자 중에서 고르는 문제**로 줄어든다

```cpp
if (K < 5) {
    cout << 0;
    return;
}

check['a' - 'a'] = true;
check['n' - 'a'] = true;
check['t' - 'a'] = true;
check['i' - 'a'] = true;
check['c' - 'a'] = true;
```

입력을 받을 때 앞뒤 고정 부분을 아예 잘라내는 것도 같은 맥락이다.

```cpp
s[i] = s[i].substr(4, s[i].size() - 8);
```

`anta`(4글자)와 `tica`(4글자)를 떼면 판단해야 할 부분만 남는다.

<br>

### 왜 백트래킹인가

"21글자 중 `K-5`개를 고르는 모든 조합"을 봐야 하고, 어떤 조합이 최적인지는 **다 세어봐야 안다.**
글자 사이에 우선순위 같은 게 없어서 그리디가 통하지 않는다.

최악의 경우 26개 중 절반쯤을 고르는 조합이라 수가 꽤 되지만, `N`이 50이고 단어 길이도 짧아서 통과한다.

<br>

### 조합을 만드는 방식

```cpp
for (int i = depth; i < 26; i++) {
    if (check[i]) continue;
    check[i] = true;
    dfs(i, k + 1);
    check[i] = false;
}
```

`depth`부터 시작하는 게 포인트다.
0부터 돌면 `{b, d}`와 `{d, b}`를 서로 다른 경우로 세게 되는데, 우리가 원하는 건 순열이 아니라 **조합**이다.
시작 인덱스를 넘겨주면 항상 뒤쪽 글자만 고르게 되어 중복이 사라진다.

`check[i] = false`로 되돌리는 것이 백트래킹이다. 이걸 빼면 한번 켠 글자가 다른 분기에도 남는다.

<br>

### 접근 방식

dfs를 돌면서 문자 하나씩 `true`로 바꿔주며, 매번 모든 단어를 확인해 읽을 수 있는 단어를 세고 최댓값을 갱신했다.

```cpp
for (int i = 0; i < N; i++) {
    bool tf = true;
    for (int j = 0; j < s[i].size(); j++) {
        if (check[s[i][j] - 'a']) continue;
        tf = false;
        break;
    }
    if (tf) count++;
}
```

단어의 모든 글자가 `check`에 들어 있으면 읽을 수 있다는 판정이다.

<br>

### 시간 복잡도

조합의 수에 매번 단어를 세는 비용 **O(N × 단어 길이)** 가 곱해진다.
`K-5`개를 21글자 중에서 고르는 조합이 최대 수십만 수준이고 `N`이 50이라 제한 안에 들어온다.

<br>

### 배운 점

어렵지 않게 풀 수 있었던 문제였다. **dfs를 응용하는 법**에 대해 잘 알 수 있었다.

다른 사람의 풀이를 보니 **각 단어를 26비트 정수로 바꿔두는** 방식이 있었다.
단어마다 "어떤 글자를 쓰는가"를 비트마스크로 미리 만들어두면, 매번 문자열을 훑지 않고 비트 연산 한 번으로 판정할 수 있다.

```
(단어비트 & ~배운비트) == 0  →  읽을 수 있음
```

문자열 비교를 정수 연산으로 바꾸는 셈이라 시간이 크게 줄어든다. 이런 방식도 인지해두어야겠다.

같은 백트래킹 유형인 [17136 색종이 붙이기](/baekjoon/2026/08/01/백준-17136-색종이-붙이기.html)와 비교하면, 이 문제는 **고정 조건을 먼저 걷어내 탐색 범위를 줄이는 것**이 핵심이었다.

<br>

---

```cpp
#include <iostream>
#include <algorithm>

using namespace std;

int N, K, result = 0;
string s[50];
string word[50];
bool check[26];

void dfs(int depth, int k) {
    if (k > K) return;

    int count = 0;

    for (int i = 0; i < N; i++) {
        bool tf = true;
        for (int j = 0; j < s[i].size(); j++) {
            if (check[s[i][j] - 'a']) continue;

            tf = false;
            break;
        }

        if (tf) count++;
    }

    if (k == K) {
        result = max(count, result);
        return;
    }

    for (int i = depth; i < 26; i++) {
        if (check[i]) continue;
        check[i] = true;
        dfs(i, k + 1);
        check[i] = false;
    }
}

void solution() {
    if (K < 5) {
        cout << 0;
        return;
    }

    check['a' - 'a'] = true;
    check['n' - 'a'] = true;
    check['t' - 'a'] = true;
    check['i' - 'a'] = true;
    check['c' - 'a'] = true;

    dfs(0, 5);

    cout << result;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL); cout.tie(NULL);

    cin >> N >> K;

    for (int i = 0; i < N; i++) {
        cin >> s[i];
        s[i] = s[i].substr(4, s[i].size() - 8);
    }

    solution();

    return 0;
}
```
