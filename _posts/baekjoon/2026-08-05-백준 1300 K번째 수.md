[1300번: K번째 수](https://www.acmicpc.net/problem/1300)

### 어떤 문제인가

`A[i][j] = i × j` 인 `N × N` 배열을 만들어 **한 줄로 쭉 펴서 정렬했을 때 `k`번째 수**를 구하는 문제다.

`N`은 최대 100,000이고 `k`는 최대 10억이다.

<br>

### 배열을 만들 수 없다

N이 100,000이면 배열의 원소가 100억 개다. 만들 수도, 정렬할 수도 없다.
그러니 **배열을 만들지 않고 답을 알아내야 한다.**

여기서 발상을 뒤집는다.
"k번째 수가 뭐지?"를 직접 묻는 대신, **"어떤 수 `r`보다 작거나 같은 값이 몇 개지?"** 를 묻는 것이다.

<br>

### 핵심 아이디어

`N = 5`일 때의 표를 보자.

| |1|2|3|4|5|
|---|---|---|---|---|---|
|1|1|2|3|4|5|
|2|2|4|6|8|10|
|3|3|6|9|12|15|
|4|4|8|12|16|20|
|5|5|10|15|20|25|

`r = 4`라고 할 때, 1행부터 차례대로 `r`보다 작거나 같은 값의 개수는 **4, 2, 1, 1, 0** 이다.

왜 그런지 보면, `i`행의 값들은 `i, 2i, 3i, ...` 이므로 `r` 이하인 것의 개수는 `r / i`개다.
다만 한 행의 길이가 `N`이라 그보다 많을 수는 없다. 그래서 이렇게 나타낼 수 있다.

```cpp
cnt += min(mid / i, N);
```

이 한 줄이면 **표를 만들지 않고도** 특정 값 이하의 개수를 O(N)에 셀 수 있다.

<br>

### 여기에 이분 탐색을 얹는다

`r`이 커질수록 "`r` 이하인 개수"는 단조 증가한다. 단조성이 있으면 이분 탐색이 된다.

- 개수 `< k` → `r`이 너무 작다 → 범위를 위로
- 개수 `>= k` → `r`이 답이 될 수 있다 → 기록해두고 범위를 아래로

```cpp
if (cnt < k) {
    s = mid + 1;
}
else {
    e = mid - 1;
    result = mid;
}
```

`cnt >= k`일 때 바로 답으로 확정하지 않고 `result`에 기록만 하고 계속 줄이는 게 포인트다.
조건을 만족하는 값 중 **가장 작은 것**을 찾아야 하기 때문이다.

탐색 범위를 `1 ~ k`로 잡은 건, `k`번째 수가 `k`보다 클 수 없기 때문이다.
1행이 `1, 2, 3, ...`이라 `k` 이하인 값이 최소 `k`개는 보장된다.

<br>

### 답이 표에 없는 값이면?

이분 탐색이 찾아낸 `mid`가 표에 실제로 존재하는 값인지 걱정될 수 있는데, 그럴 필요가 없다.

"`x` 이하가 `k`개 이상"인 가장 작은 `x`는 **반드시 표에 있는 값**이다.
표에 없는 값이라면 그보다 1 작은 값도 같은 개수를 가지므로, 더 작은 쪽이 답이 되어야 하기 때문이다.

<br>

### 시간 복잡도

이분 탐색이 **O(log k)**, 매 단계마다 개수를 세는 데 **O(N)**.
전체 **O(N log k)** 로, 100,000 × 30 = 300만 번 수준이다.

100억 개를 만들어 정렬하는 것과 비교하면 완전히 다른 차원이다.

<br>

### 배운 점

굉장히 어려웠던 문제였다.
처음 아이디어를 잘못 생각해 시간을 많이 날렸고, 블로그를 참고했을 때도 이해하기가 어려웠다.

이번 문제의 키포인트는 **이분 탐색이 아니라 사실상 구현 아이디어**였다고 생각한다.
이분 탐색 자체는 기본이지만, "무엇을 대상으로 이분 탐색할 것인가"를 떠올리는 게 전부인 문제였다.

정리하면 이 유형은 이렇게 접근한다.

- 답을 직접 구하기 어렵다
- 대신 **"답이 x라고 가정했을 때 조건을 만족하는가"** 는 빠르게 판단할 수 있다
- 그 판단이 단조적이면 답을 이분 탐색한다

이걸 **매개변수 탐색(파라메트릭 서치)** 이라고 부른다는 것도 나중에 알았다.
비슷한 유형을 더 풀어봐야겠다.

<br>

---

```cpp
#include <iostream>
#include <algorithm>

using namespace std;

int N, k, result = 0;

void solution() {
	int s = 1, e = k;


	while (s <= e) {
		int mid = (s + e) / 2;
		int cnt = 0;

		for (int i = 1; i <= N; i++) {
			cnt += min(mid / i, N);
		}

		if (cnt < k) {
			s = mid + 1;
		}
		else {
			e = mid - 1;
			result = mid;
		}
	}
	
	cout << result;
}

int main(){
	ios_base::sync_with_stdio(false);
	cin.tie(NULL); cout.tie(NULL);

	cin >> N;
	cin >> k;

	solution();
	
	return 0;
}

```
