[1774번: 우주신과의 교감](https://www.acmicpc.net/problem/1774)

### 어떤 문제인가

평면 위에 우주신 `N`개의 좌표가 주어지고, 그중 일부는 **이미 연결되어 있다.**
나머지를 전부 이어 모두가 통하게 만들 때, 새로 만들어야 하는 통로 길이의 합을 최소로 하는 문제다.

통로 길이는 두 점 사이의 직선 거리(유클리드 거리)이고, `N`과 이미 연결된 쌍의 수 `M` 모두 최대 1,000이다.

<br>

### 왜 최소 스패닝 트리인가

"전부 연결하되 총 길이 최소"는 MST 그대로다.
이 문제만의 특징은 **일부 간선이 이미 놓여 있고, 그건 공짜**라는 점이다.

여기서 헤맬 수 있는데, 처리는 의외로 간단하다.
크루스칼을 시작하기 **전에** 이미 연결된 쌍들을 먼저 `union` 해버리면 된다.

```cpp
for (int i = 0; i < M; i++) {
    int a = m[i].first;
    int b = m[i].second;
    if (a > b) swap(a, b);
    unionParent(a, b);
}
```

이렇게 해두면 그 쌍들은 이미 같은 집합에 속하므로, 나중에 크루스칼이 그 사이를 잇는 간선을 만나도 `sameParent`에 걸려 자동으로 건너뛴다.
"공짜 간선"을 비용 0으로 취급해 따로 넣을 필요 없이, **집합만 미리 합쳐두면 되는** 구조다.

<br>

### 접근 방식

크루스칼 알고리즘을 사용하기 위해 **가중치와 경로를 구하는 것**이 중요한 포인트다.

1. 부모 노드를 나타내는 `p` 배열을 초기화한다
2. 입력으로 받은 이미 연결된 경로를 모두 `union` 해준다
3. 각 노드 간의 모든 경로와 거리를 구한다
4. 오름차순으로 정렬한 뒤 크루스칼을 돌면서 가중치를 더한다
5. 소수점 둘째 자리까지 출력한다

거리는 두 점 사이 직선 거리를 그대로 쓴다.

```cpp
long long a = (long long) pow(n[i].first - n[j].first, 2);
long long b = (long long) pow(n[i].second - n[j].second, 2);
double c = (double) sqrt(a + b);
```

좌표가 최대 1,000,000이라 차이의 제곱이 10¹²까지 갈 수 있어서 `long long`으로 받았다.
다만 `pow`는 부동소수점 함수라 정수 제곱에 쓰면 미세하게 어긋난 값이 나올 수 있다. `(long long)(dx) * dx`처럼 **직접 곱하는 편이 안전하고 빠르다.**

출력은 소수점 둘째 자리 고정이다.

```cpp
cout << fixed;
cout.precision(2);
```

<br>

### 시간 복잡도

모든 쌍의 거리를 구하므로 간선이 `N(N-1)/2`개, N이 1,000이면 약 50만 개다.
여기에 정렬 **O(E log E)** 가 붙는다. N이 작아서 이 방식으로 통과한다.

<br>

### 배운 점

어렵지 않게 풀 수 있었던 문제였다.
단순히 모든 경로와 가중치를 구해 해결했지만, 사실 필요한 것은 `N-1`개의 간선뿐이라 시간을 더 줄일 여지가 있다.

크루스칼을 쓰기 위해 **입력을 간선 목록으로 만들어내는** 이 방식도 인지해두자.

이 문제는 N이 1,000이라 모든 쌍을 만들어도 됐지만, [2887 행성 터널](/baekjoon/2026/08/24/백준-2887-행성-터널.html)은 N이 100,000이라 같은 방식이 통하지 않는다.
**N의 크기가 "모든 쌍을 만들어도 되는가"를 가르는 기준**이라는 걸 두 문제를 나란히 풀면서 알게 됐다.

MST 유형은 [1647 도시 분할 계획](/baekjoon/2026/08/27/백준-1647-도시-분할-계획.html)도 함께 정리해뒀다.

<br>

---

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>

using namespace std;

int N, M;
vector<pair<int, int>> n;
vector<pair<int, int>> m;
vector<pair<double, pair<int, int>>> v;
int p[1001];
double result = 0;

int findParent(int a) {
    if (a == p[a]) return a;
    else return p[a] = findParent(p[a]);
}

void unionParent(int a, int b) {
    a = findParent(a);
    b = findParent(b);

    if (a != b) p[a] = b;
}

bool sameParent(int a, int b) {
    a = findParent(a);
    b = findParent(b);

    if (a == b) return true;
    else return false;
}

void findRoot() {
    for (int i = 0; i < N; i++) {
        for (int j = i + 1; j < N; j++) {
            long long a = (long long) pow(n[i].first - n[j].first, 2);
            long long b = (long long) pow(n[i].second - n[j].second, 2);
            double c = (double) sqrt(a + b);
            
            v.push_back({ c, {i + 1,j + 1} });
        }
    }
}

void solution() {
    for (int i = 1; i <= N; i++) {
        p[i] = i;
    }

    for (int i = 0; i < M; i++) {
        int a = m[i].first;
        int b = m[i].second;

        if (a > b) swap(a, b);

        unionParent(a, b);
    }

    findRoot();

    sort(v.begin(), v.end());

    for (int i = 0; i < v.size(); i++) {
        int a = v[i].second.first;
        int b = v[i].second.second;
        double c = v[i].first;

        if (!sameParent(a, b)) {
            unionParent(a, b);
            result += c;
        }
    }

    cout << fixed;
    cout.precision(2);
    cout << result;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL); cout.tie(NULL);

    cin >> N >> M;

    int a, b;
    for (int i = 0; i < N; i++) {
        cin >> a >> b;
        n.push_back({ a,b });
    }

    for (int i = 0; i < M; i++) {
        cin >> a >> b;
        m.push_back({ a,b });
    }

    solution();

    return 0;
}
```
