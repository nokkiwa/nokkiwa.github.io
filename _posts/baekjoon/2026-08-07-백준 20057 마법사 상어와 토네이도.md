[20057번: 마법사 상어와 토네이도](https://www.acmicpc.net/problem/20057)

### 어떤 문제인가

`N × N` 격자의 각 칸에 모래가 있고, 토네이도가 **가운데에서 시작해 달팽이 모양으로** 격자를 돌며 모래를 흩뿌린다.
토네이도가 왼쪽 위 끝에 도달했을 때, **격자 밖으로 나간 모래의 총량**을 구하는 문제다.

`N`은 3 이상 499 이하의 홀수다.

<br>

### 알고리즘이 아니라 구현 문제다

이 문제에는 떠올려야 할 알고리즘이 없다.
문제에 주어진 규칙을 **틀리지 않고 그대로 옮기는 것**이 전부다. 그래서 오히려 시간이 오래 걸린다.

구현할 것은 두 가지다.

1. 토네이도의 이동 (달팽이 경로)
2. 모래의 이동 (비율에 따른 분배)

<br>

### 1. 달팽이 이동에서 찾은 규칙

토네이도는 왼쪽 → 아래 → 오른쪽 → 위 순으로 돌면서 이동 거리가 점점 늘어난다.
직접 그려보면 규칙이 보인다.

```
1칸 왼쪽 → 1칸 아래 → 2칸 오른쪽 → 2칸 위 →
3칸 왼쪽 → 3칸 아래 → 4칸 오른쪽 → 4칸 위 → ...
```

즉 **한 바퀴마다 이동 칸 수가 2씩 늘어나고, 오른쪽·위쪽은 왼쪽·아래쪽보다 1칸씩 더 간다.**
이걸 `move` 변수 하나로 표현했다.

```cpp
while (1) {
    step1(step);        // 왼쪽

    if (y == 2 && x == 2) break;

    step2(step);        // 아래
    step3(step + 1);    // 오른쪽
    step4(step + 1);    // 위

    step += 2;
}
```

도착 지점(왼쪽 위 모서리)에는 항상 **왼쪽으로 이동하는 중**에 닿기 때문에, `step1`을 끝낸 뒤 좌표를 확인해 멈춰준다.

<br>

### 2. 격자 밖 모래를 세는 요령

모래가 격자 밖으로 날아가는 걸 매번 `if`로 검사하면 조건문이 폭발한다.
그래서 **배열 자체를 `N+4` 크기로 잡고 실제 격자를 안쪽에 두는** 방식을 썼다.

```cpp
for (int i = 2; i < N + 2; i++)
    for (int j = 2; j < N + 2; j++)
        cin >> A[i][j];
```

모래가 퍼지는 최대 거리가 3칸이므로 사방에 2칸씩 여유를 두면 범위를 벗어나는 접근이 없다.
마지막에 **바깥 테두리에 쌓인 모래를 전부 더하면** 그게 답이다.

```cpp
for (int i = 0; i < N + 4; i++) {
    for (int j = 0; j < N + 4; j++) {
        if (i >= 2 && i < N + 2 && j >= 2 && j < N + 2) continue;
        result += A[i][j];
    }
}
```

경계 검사를 배열 크기로 대신한 셈이다. 격자 문제에서 자주 쓰이는 방법이다.

<br>

### 3. 남은 모래(α) 처리

각 비율(1%, 7%, 2%, 10%, 5%)로 나눠준 뒤 **남은 모래는 전부 한 칸으로** 간다.
비율 계산에서 소수점이 버려지므로, 나눠준 양을 하나씩 빼서 남은 값을 구해야 한다.

```cpp
int tmp = sand;
A[y - 1][x] += sand * 0.01;
tmp -= (int)(sand * 0.01);
...
A[y][x - 2] += tmp;     // 남은 모래
```

여기서 주의할 점이 있다. `sand * 0.01`은 실수 연산이라 `300 * 0.01`이 `2.9999...`로 나올 여지가 있고, 그러면 잘라낼 때 3이 아니라 2가 된다.
`sand * 1 / 100`처럼 **정수 연산으로 계산하는 편이 안전하다.**

모래 이동은 방향마다 좌표 부호가 달라져서, 깔끔하게 표현할 방법을 찾지 못하고 네 방향을 하나씩 구현했다.

<br>

### 시간 복잡도

토네이도가 모든 칸을 정확히 한 번씩 지나가고, 칸마다 상수 개(9곳)에 모래를 뿌린다.
따라서 **O(N²)** 이다. N이 499면 약 25만 칸이라 여유롭다.

<br>

### 배운 점

역시 구현 문제는 시간이 오래 걸리는 유형이다.
구현 자체는 어렵지 않은데 사실상 노가다라 시간이 굉장히 오래 걸렸다.

그리고 **문제를 잘못 읽는 바람에 모래의 이동 조건을 잘못 생각한** 점도 있었다.
비율표가 왼쪽으로 이동할 때 기준이라는 걸 놓치고, 네 방향에 같은 좌표를 그대로 썼다가 한참을 헤맸다.

구현 문제를 풀 때는 **조건을 제대로 이해하는 것이 가장 중요하다**는 점을 인지하자.
코드를 쓰기 전에 방향 하나를 종이에 그려서 좌표를 확정하고, 나머지는 거기서 회전시켜 옮기는 순서가 확실했을 것 같다.

<br>

```cpp
#include <iostream>

using namespace std;

int N, y, x, result = 0;
int A[504][504];

void step1(int move) {
    while (move--) {
        int sand = A[y][x - 1];
        int tmp = sand;

        A[y - 1][x] += sand * 0.01;
        tmp -= (int)(sand * 0.01);
        A[y + 1][x] += sand * 0.01;
        tmp -= (int)(sand * 0.01);
        A[y - 1][x - 1] += sand * 0.07;
        tmp -= (int)(sand * 0.07);
        A[y + 1][x - 1] += sand * 0.07;
        tmp -= (int)(sand * 0.07);
        A[y - 2][x - 1] += sand * 0.02;
        tmp -= (int)(sand * 0.02);
        A[y + 2][x - 1] += sand * 0.02;
        tmp -= (int)(sand * 0.02);
        A[y - 1][x - 2] += sand * 0.1;
        tmp -= (int)(sand * 0.1);
        A[y + 1][x - 2] += sand * 0.1;
        tmp -= (int)(sand * 0.1);
        A[y][x - 3] += sand * 0.05;
        tmp -= (int)(sand * 0.05);

        A[y][x - 2] += tmp;
        A[y][x - 1] = 0;

        x--;
        if (y == 2 && x == 2) break;
    }
}

void step2(int move) {
    while (move--) {
        int sand = A[y + 1][x];
        int tmp = sand;

        A[y][x - 1] += sand * 0.01;
        tmp -= (int)(sand * 0.01);
        A[y][x + 1] += sand * 0.01;
        tmp -= (int)(sand * 0.01);
        A[y + 1][x - 1] += sand * 0.07;
        tmp -= (int)(sand * 0.07);
        A[y + 1][x + 1] += sand * 0.07;
        tmp -= (int)(sand * 0.07);
        A[y + 1][x - 2] += sand * 0.02;
        tmp -= (int)(sand * 0.02);
        A[y + 1][x + 2] += sand * 0.02;
        tmp -= (int)(sand * 0.02);
        A[y + 2][x - 1] += sand * 0.1;
        tmp -= (int)(sand * 0.1);
        A[y + 2][x + 1] += sand * 0.1;
        tmp -= (int)(sand * 0.1);
        A[y + 3][x] += sand * 0.05;
        tmp -= (int)(sand * 0.05);

        A[y + 2][x] += tmp;
        A[y + 1][x] = 0;
        y++;
    }
}

void step3(int move) {
    while(move--) {
        int sand = A[y][x + 1];
        int tmp = sand;

        A[y - 1][x] += sand * 0.01;
        tmp -= (int)(sand * 0.01);
        A[y + 1][x] += sand * 0.01;
        tmp -= (int)(sand * 0.01);
        A[y - 1][x + 1] += sand * 0.07;
        tmp -= (int)(sand * 0.07);
        A[y + 1][x + 1] += sand * 0.07;
        tmp -= (int)(sand * 0.07);
        A[y - 2][x + 1] += sand * 0.02;
        tmp -= (int)(sand * 0.02);
        A[y + 2][x + 1] += sand * 0.02;
        tmp -= (int)(sand * 0.02);
        A[y - 1][x + 2] += sand * 0.1;
        tmp -= (int)(sand * 0.1);
        A[y + 1][x + 2] += sand * 0.1;
        tmp -= (int)(sand * 0.1);
        A[y][x + 3] += sand * 0.05;
        tmp -= (int)(sand * 0.05);

        A[y][x + 2] += tmp;
        A[y][x + 1] = 0;
        x++;
    }
}

void step4(int move) {
    while (move--) {
        int sand = A[y - 1][x];
        int tmp = sand;

        A[y][x - 1] += sand * 0.01;
        tmp -= (int)(sand * 0.01);
        A[y][x + 1] += sand * 0.01;
        tmp -= (int)(sand * 0.01);
        A[y - 1][x - 1] += sand * 0.07;
        tmp -= (int)(sand * 0.07);
        A[y - 1][x + 1] += sand * 0.07;
        tmp -= (int)(sand * 0.07);
        A[y - 1][x - 2] += sand * 0.02;
        tmp -= (int)(sand * 0.02);
        A[y - 1][x + 2] += sand * 0.02;
        tmp -= (int)(sand * 0.02);
        A[y - 2][x - 1] += sand * 0.1;
        tmp -= (int)(sand * 0.1);
        A[y - 2][x + 1] += sand * 0.1;
        tmp -= (int)(sand * 0.1);
        A[y - 3][x] += sand * 0.05;
        tmp -= (int)(sand * 0.05);

        A[y - 2][x] += tmp;
        A[y - 1][x] = 0;
        y--;
    }
}

void solution() {
    y = (N + 4) / 2;
    x = (N + 4) / 2;
    int step = 1;

    while (1) {
        step1(step);

        if (y == 2 && x == 2) break;

        step2(step);
        step3(step + 1);
        step4(step + 1);

        step += 2;
    }

    for (int i = 0; i < N + 4; i++) {
        for (int j = 0; j < N + 4; j++) {
            if (i >= 2 && i < N + 2 && j >= 2 && j < N + 2) continue;
            result += A[i][j];
        }
    }

    cout << result;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL); cout.tie(NULL);

    cin >> N;

    for (int i = 2; i < N + 2; i++) {
        for (int j = 2; j < N + 2; j++) {
            cin >> A[i][j];
        }
    }

    solution();

    return 0;
}
```
