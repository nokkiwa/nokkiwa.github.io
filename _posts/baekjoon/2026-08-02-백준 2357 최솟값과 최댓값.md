[2357번: 최솟값과 최댓값](https://www.acmicpc.net/problem/2357)

### 어떤 문제인가

`N`개의 정수가 주어지고, `a`번째부터 `b`번째까지의 **최솟값과 최댓값을 동시에** 구하는 질의가 `M`개 들어온다.
`N`과 `M` 모두 최대 100,000이다.

<br>

### 왜 세그먼트 트리인가

질의마다 구간을 직접 훑으면 한 번에 최대 100,000번, 질의가 100,000개니 **최악 100억 번**이다. 당연히 시간 초과다.

구간의 최솟값·최댓값을 미리 계산해 두고 재사용해야 하는데, 이게 **세그먼트 트리**가 하는 일이다.

트리의 각 노드가 어떤 구간을 담당하고, 그 구간의 최솟값·최댓값을 들고 있다.
질의가 들어오면 필요한 노드 몇 개만 조합해서 답을 만든다. 구간 전체를 훑지 않는다.

값이 바뀌지 않는 문제라 희소 배열(Sparse Table)로도 풀 수 있지만, 세그먼트 트리가 갱신까지 대응되는 더 일반적인 도구다.

<br>

### 최솟값과 최댓값을 같이 담기

두 값을 따로 트리 두 개로 만들 수도 있지만, `pair`로 한 노드에 같이 담으면 트리 하나로 끝난다.

```cpp
vector<pair<int, int>> tree;   // {최솟값, 최댓값}
```

트리를 만들 때는 왼쪽·오른쪽 자식의 결과를 받아 합친다.

```cpp
pair<int, int> a = createTree(start, mid, idx * 2);
pair<int, int> b = createTree(mid + 1, end, idx * 2 + 1);

int min_value = a.first < b.first ? a.first : b.first;
int max_value = a.second > b.second ? a.second : b.second;
```

리프(`start == end`)에서는 그 원소 하나가 최솟값이자 최댓값이다.

트리 크기를 `N * 4`로 잡는 것도 관례다.
완전 이진 트리로 채우면 `2 * 2^ceil(log2(N))`까지 필요한데, `4N`으로 잡으면 어떤 `N`에서도 넉넉하다.

<br>

### 질의를 처리하는 세 가지 경우

여기서 헤맸다. `findTree`는 현재 노드의 구간과 질의 구간의 관계를 세 가지로 나눈다.

```cpp
if (start > b || end < a) return { 1e9, 0 };   // 1. 아예 겹치지 않음
if (a <= start && end <= b) return tree[idx];  // 2. 완전히 포함됨
// 3. 걸쳐 있음 → 양쪽으로 쪼개서 재귀
```

**1번의 반환값이 포인트다.**
겹치지 않는 구간은 답에 영향을 주면 안 되므로, 최솟값 자리에는 아주 큰 값(`1e9`)을, 최댓값 자리에는 아주 작은 값(`0`)을 돌려준다.
그래야 위에서 비교할 때 자연스럽게 무시된다.

이 문제는 입력이 1 이상이라 최댓값 쪽에 `0`을 써도 되지만, 음수가 들어올 수 있는 문제라면 충분히 작은 음수로 잡아야 한다.

<br>

### 시간 복잡도

- 트리 생성: **O(N)**
- 질의 하나: **O(log N)**

전체 **O(N + M log N)** 이다. 100,000개 질의에 로그가 붙는 정도라 여유롭다.

<br>

### 배운 점

생각보다 어려웠던 문제였다.
세그먼트 트리를 이용한다는 것까지는 생각해냈는데 **결과를 찾는 과정에서 좀 헤맸다.**

특히 겹치지 않는 구간에서 무엇을 돌려줄지가 막혔던 부분이다.
"영향을 주지 않는 값"을 돌려준다는 개념이 잡히고 나서야 코드가 정리됐다. 최솟값을 구할 때는 아주 큰 값, 최댓값을 구할 때는 아주 작은 값이다.

세그먼트 트리는 구간 합, 구간 최소, 구간 최대 등 **무엇을 담느냐만 바뀌고 뼈대는 같다.**
합치는 방식(`min`, `max`, `+`)만 갈아끼우면 되는 구조라는 걸 알게 됐다. 세그먼트 트리에 대해 잘 알아두어야겠다.

<br>

```cpp
#include <iostream>
#include <vector>

using namespace std;

int N, M;
vector<int> n;
vector<pair<int, int>> m;
vector<pair<int, int>> tree;

pair<int, int> createTree(int start, int end, int idx) {
	if (start == end) return tree[idx] = { n[start], n[start] };

	int mid = (start + end) / 2;

	pair<int, int> a = createTree(start, mid, idx * 2);
	pair<int, int> b = createTree(mid + 1, end, idx * 2 + 1);

	int min_value = a.first < b.first ? a.first : b.first;
	int max_value = a.second > b.second ? a.second : b.second;

	return tree[idx] = { min_value, max_value };
}

pair<int, int> findTree(int start, int end, int a, int b, int idx) {
	if (start > b || end < a) return { 1e9, 0 };
	if (a <= start && end <= b) return tree[idx];

	int mid = (start + end) / 2;

	pair<int, int> node1 = findTree(start, mid, a, b, idx * 2);
	pair<int, int> node2 = findTree(mid + 1, end, a, b, idx * 2 + 1);

	int min_value = node1.first < node2.first ? node1.first : node2.first;
	int max_value = node1.second > node2.second ? node1.second : node2.second;

	return { min_value, max_value };
}

void solution() {
	tree.resize(N * 4);
	createTree(1, N, 1);

	for (int i = 0; i < M; i++) {
		int a = m[i].first;
		int b = m[i].second;

		pair<int, int> result = findTree(1, N, a, b, 1);
		cout << result.first << " " << result.second << "\n";
	}
}

int main(){
	ios_base::sync_with_stdio(false);
	cin.tie(NULL); cout.tie(NULL);

	cin >> N >> M;

	n.push_back(-1);
	int c;
	for (int i = 0; i < N; i++) {
		cin >> c;
		n.push_back(c);
	}

	int a, b;
	for (int i = 0; i < M; i++) {
		cin >> a >> b;
		m.push_back({ a, b });
	}

	solution();
	
	return 0;
}

```
