[16948번: 데스 나이트](https://www.acmicpc.net/problem/16948)

### 어떤 문제인가

`N × N` 체스판에서 데스 나이트가 정해진 여섯 방향으로만 움직일 수 있다.
`(r1, c1)`에서 `(r2, c2)`까지 가는 **최소 이동 횟수**를 구하고, 갈 수 없으면 `-1`을 출력하는 문제다.

`N`은 5 이상 200 이하다.

<br>

### 왜 BFS인가

"최소 이동 횟수"이고 **한 번 움직이는 비용이 전부 1**이다.
가중치가 모두 같으면 BFS로 찾은 첫 도달 경로가 곧 최단 경로다. 다익스트라 같은 걸 쓸 필요가 없다.

BFS는 시작점에서 거리 1인 칸을 전부 본 다음 거리 2인 칸을 보는 식으로 퍼져나가기 때문에, 목적지에 처음 닿는 순간이 최단 거리라는 게 보장된다.
DFS로 풀면 먼저 찾은 경로가 최단이라는 보장이 없어서 모든 경로를 다 봐야 한다.

<br>

### 이동 방향을 배열로 빼기

이 문제에서 실질적으로 할 일은 여섯 방향을 정확히 옮겨 적는 것이다.

```cpp
int dy[6] = { -2,-2,0,0,2,2 };
int dx[6] = { -1,1,-2,2,-1,1 };
```

`(-2,-1)`, `(-2,1)`, `(0,-2)`, `(0,2)`, `(2,-1)`, `(2,1)` 여섯 가지를 `dy`, `dx` 배열로 나눠 담았다.
이렇게 해두면 반복문 하나로 전부 순회할 수 있어서, 방향마다 `if`를 쓰는 것보다 훨씬 덜 틀린다.

```cpp
for (int i = 0; i < 6; i++) {
    int ny = y + dy[i];
    int nx = x + dx[i];

    if (ny < 0 || nx < 0 || ny >= N || nx >= N) continue;
    if (check[ny][nx]) continue;
    ...
}
```

두 개의 `continue`가 각각 **격자 밖 검사**와 **방문 검사**다.
방문 검사를 빼면 같은 칸을 계속 오가면서 큐가 무한히 불어난다.

<br>

### 방문 표시를 넣는 시점

BFS에서 자주 틀리는 지점이 방문 표시를 언제 하느냐다.

```cpp
q.push({ {ny,nx},count + 1 });
check[ny][nx] = true;
```

큐에 **넣는 순간** 방문 처리를 해야 한다.
꺼낼 때 처리하면, 아직 큐에 있지만 아직 안 꺼낸 칸을 다른 경로가 또 넣어버려서 같은 칸이 여러 번 들어간다. 정답은 나와도 시간과 메모리가 낭비된다.

거리는 별도 배열 대신 큐에 `count`를 같이 담아 관리했다.

<br>

### 시간 복잡도

각 칸을 한 번씩만 방문하고 칸마다 여섯 방향을 보므로 **O(N²)** 이다.
N이 200이면 40,000칸이라 아주 여유롭다.

<br>

### 배운 점

간단한 BFS 구현 문제로, 문제에서 주어진 이동 조건을 `dy`, `dx`로 구현해 풀었다.
쉽게 풀 수 있었던 문제였는데 **오타로 인해 시간 낭비가 좀 있었다.**

구체적으로는 `dy`, `dx` 배열의 값을 옮겨 적으면서 부호를 하나 잘못 넣었다.
이런 실수는 컴파일도 되고 실행도 되니까 결과가 틀릴 때까지 안 보인다.

방향 배열을 쓸 때는 옮겨 적은 뒤에 **문제의 그림과 한 쌍씩 대조하는 습관**을 들이는 게 낫겠다.
`result`를 `-1`로 초기화해둔 것도 같은 이유인데, 도달 못 하면 그대로 `-1`이 출력되므로 별도 분기가 필요 없다.

가중치가 있는 최단 경로는 [5972 택배 배송](/baekjoon/2026/08/21/백준-5972-택배-배송.html)에서 다익스트라로 풀었다. 이 문제와 비교하면 BFS로 충분한 조건이 무엇인지 정리된다.

<br>

---

```cpp
#include <iostream>
#include <queue>

using namespace std;

int N, result = -1;
int r1, c1, r2, c2;
int dy[6] = { -2,-2,0,0,2,2 };
int dx[6] = { -1,1,-2,2,-1,1 };
bool check[200][200];

void bfs() {
	queue<pair<pair<int, int>, int>> q;

	q.push({ {r1,c1},0 });
	check[r1][c1] = true;

	while (!q.empty()) {
		int y = q.front().first.first;
		int x = q.front().first.second;
		int count = q.front().second;

		if (y == r2 && x == c2) {
			result = count;
			break;
		}

		q.pop();

		for (int i = 0; i < 6; i++) {
			int ny = y + dy[i];
			int nx = x + dx[i];

			if (ny < 0 || nx < 0 || ny >= N || nx >= N) continue;
			if (check[ny][nx]) continue;

			q.push({ {ny,nx},count + 1 });
			check[ny][nx] = true;
		}
	}
}

void solution() {
	bfs();

	cout << result;
}

int main(){
	ios_base::sync_with_stdio(false);
	cin.tie(NULL); cout.tie(NULL);

	cin >> N;
	cin >> r1 >> c1 >> r2 >> c2;

	solution();
	
	return 0;
}
```
