[5052번: 전화번호 목록](https://www.acmicpc.net/problem/5052)

### 어떤 문제인가

전화번호 목록이 주어질 때, **어떤 번호가 다른 번호의 접두어인지**를 판별하는 문제다.

예를 들어 `911`과 `91125426`이 같이 있으면, `911`로 걸려던 전화가 뒤 번호로 이어질 수 있으니 일관성이 없다.
일관성이 있으면 `YES`, 아니면 `NO`를 출력한다.

테스트 케이스마다 번호가 최대 10,000개, 번호 길이는 10자리 이하다.

<br>

### 정렬이 절반을 해결한다

모든 쌍을 비교하면 1억 번이라 부담스럽다. 그런데 **사전순으로 정렬해두면** 상황이 달라진다.

어떤 번호가 다른 번호의 접두어라면, 정렬했을 때 그 둘은 반드시 가까이 모인다.
`911`은 `91125426`보다 항상 앞에 오고, 접두어가 되는 쪽이 먼저 나온다.

그래서 **앞에서부터 하나씩 처리하면서, 지금 번호의 접두어가 이미 등장했는지만** 확인하면 된다.

<br>

### 접근 방식

먼저 모든 입력을 벡터로 받아 오름차순으로 정렬한다.
그리고 반복문을 돌며 해당 전화번호의 한 글자씩 `tmp`에 넣어보며 집합에 있는지 확인한다.

```cpp
for (int j = 0; j < v[i].size() - 1; j++) {
    tmp += v[i][j];

    if (set.find(tmp) != set.end()) {
        cout << "NO\n";
        return;
    }
}

set.insert(v[i]);
```

`v[i]`의 모든 접두어(`9`, `91`, `911`, ...)를 만들어보고, 그중 하나라도 이미 저장된 번호와 같으면 접두어 관계가 성립한다는 뜻이다.

반복 조건이 `size() - 1`인 것에 주의해야 한다.
자기 자신까지 만들면 방금 넣으려는 번호와 같아져서 항상 걸리게 된다. **자기 자신은 접두어로 보지 않는다.**

끝까지 통과하면 `YES`를 출력한다.

<br>

### 시간 복잡도

정렬 **O(n log n)** 에, 번호마다 접두어를 최대 10개 만들어 해시 조회를 한다.
조회가 평균 O(1)이라 전체적으로 정렬이 지배적이다.

<br>

### 배운 점

간단하게 풀 수 있었던 문제였다.

사실 해시 셋(`unordered_set`)이 아니라 이진 트리 방식인 `set`을 써도 통과한다.
이번 문제는 케이스가 많지 않아 해시 셋이 더 빠를 것으로 보고 `unordered_set`을 썼다.

다만 해시 셋이 항상 빠른 건 아니다. 해시 충돌이 많아지면 오히려 느려질 수 있고, 문자열 해싱 비용도 있다.
데이터 성격에 따라 갈리는 부분이라는 걸 알아두면 좋겠다.

그리고 **트라이(Trie)** 라는 방식으로도 이 문제를 풀 수 있다는 걸 알게 됐다.
문자를 노드로 하는 트리를 만들어 번호를 한 글자씩 따라 내려가는 자료구조인데, 접두어 판별에는 이게 정석에 가깝다.
정렬이 필요 없고 삽입하면서 바로 판정할 수 있다. 처음 보는 개념이라 신기했고, 트라이에 대해서도 공부해봐야겠다.

<br>

---

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <unordered_set>

using namespace std;

int n;
vector<string> v;
unordered_set<string> set;

void solution() {
    sort(v.begin(), v.end());

    for (int i = 0; i < n; i++) {
        string tmp = "";

        for (int j = 0; j < v[i].size() - 1; j++) {
            tmp += v[i][j];

            if (set.find(tmp) != set.end()) {
                cout << "NO\n";
                return;
            }
        }

        set.insert(v[i]);
    }

    cout << "YES\n";
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL); cout.tie(NULL);

    int t;
    cin >> t;

    while (t--) {
        v.clear();
        set.clear();

        cin >> n;

        string s;
        for (int i = 0; i < n; i++) {
            cin >> s;
            v.push_back(s);
        }

        solution();
    }

    return 0;
}
```
