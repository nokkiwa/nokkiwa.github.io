[11657번: 타임머신](https://www.acmicpc.net/problem/11657)

### 어떤 문제인가

도시 `N`개와 버스 노선 `M`개가 있는데, **이동에 걸리는 시간이 음수일 수도 있다.**
1번 도시에서 나머지 도시로 가는 최단 시간을 구하되, 시간을 무한히 되돌릴 수 있으면 `-1`을 출력하는 문제다.

`N`은 최대 500, `M`은 최대 6,000이고 가중치는 -10,000 ~ 10,000이다.

<br>

### 왜 다익스트라가 아니라 벨만 포드인가

최단 거리 문제를 보면 반사적으로 다익스트라를 떠올리게 되는데, **여기서는 쓸 수 없다.**

다익스트라는 "지금까지 찾은 가장 짧은 경로는 앞으로 더 짧아질 수 없다"는 전제로 확정을 짓는다.
그런데 음수 간선이 있으면 나중에 음수 간선을 타고 돌아와 더 짧아질 수 있어서 그 전제가 깨진다.

그래서 음수 가중치가 있으면 **벨만 포드**다.
벨만 포드는 확정을 짓지 않고 **모든 간선을 N-1번 반복해서 훑으며** 거리를 계속 갱신한다.

`N-1`번인 이유는, 사이클이 없는 최단 경로가 최대 `N-1`개의 간선으로 이루어지기 때문이다.
한 번 순회할 때마다 최소 한 개의 정점이 확정되므로 `N-1`번이면 충분하다.

<br>

### 음수 사이클을 잡는 법

여기가 이 문제의 진짜 포인트다.
`N-1`번을 다 돌았으면 더 이상 갱신될 게 없어야 한다. 그런데 **한 번 더 돌렸을 때도 값이 줄어든다면**, 돌수록 짧아지는 경로가 있다는 뜻이다. 그게 음수 사이클이다.

```cpp
for (int i = 0; i < M; i++) {
    if (d[from] == INF) continue;
    if (d[to] > d[from] + cost) {
        cout << -1;
        return;
    }
}
```

`N-1`번 순회가 끝난 뒤 같은 검사를 한 번 더 돌려서, 갱신이 일어나면 `-1`을 출력한다.

<br>

### 접근 방식

기존 벨만 포드와 동일하게 구현하면 된다.
다만 도달할 수 없는 도시가 있을 수 있어서, `d[from] == INF`일 경우 `continue`하는 조건을 추가했다.

```cpp
if (d[from] == INF || d[to] <= d[from] + cost) continue;
```

이 조건이 왜 필요하냐면, 아직 도달하지 못한 도시(`INF`)에서 **음수 간선**을 타면 `INF + (-10000)`이 되어 `INF`보다 작아진다.
그러면 갈 수 없는 도시가 갈 수 있는 것처럼 갱신되어 버린다.

`INF`를 `4e10`으로 크게 잡고 `d`를 `long long`으로 둔 것도 같은 맥락이다.
`int`의 최댓값 근처로 잡으면 여러 번 더해지면서 오버플로가 나 음수로 뒤집힐 수 있다.

<br>

### 시간 복잡도

간선 전체를 `N-1`번 훑으므로 **O(N × M)** 이다.
500 × 6,000 = 300만 번이라 여유롭다.

다익스트라의 O(E log V)보다 느리지만, 음수 간선이 있으면 선택지가 없다.

<br>

### 배운 점

생각보다 오래 걸린 문제였다.
음수 가중치가 존재하고 최단 거리를 구해야 한다는 점에서 벨만 포드는 금방 유추해냈는데, **자료형, 최댓값, 조건문, 음수 사이클 찾기**를 잘못 설정해 계속 틀렸다.

정리하면 이 문제에서 틀리기 쉬운 지점이 네 군데였다.

- `d` 배열을 `int`로 두어 오버플로
- `INF`를 너무 작게 잡아 음수 간선과 더해지며 갱신됨
- `d[from] == INF` 검사를 빼먹어 도달 불가 도시가 갱신됨
- 음수 사이클 검사를 `N-1`번 안에 섞어버림

전부 문제를 꼼꼼히 읽지 않아 생긴 일이었다. 문제를 잘 읽어보고 풀도록 하자.

음수 간선이 없는 최단 경로는 [5972 택배 배송](/baekjoon/2026/08/21/백준-5972-택배-배송.html)에서 다익스트라로 풀었다. 두 문제를 비교해보면 언제 무엇을 쓰는지가 선명해진다.

<br>

---

```cpp
#include <iostream>
#include <vector>

#define INF 4e10

using namespace std;

int N, M;
vector<pair<pair<int, int>, long long>> v;
long long d[501];

void solution() {
	for (int i = 1; i <= N; i++) {
		d[i] = INF;
	}

	d[1] = 0;

	for (int i = 0; i < N - 1; i++) {
		for (int j = 0; j < M; j++) {
			int from = v[j].first.first;
			int to = v[j].first.second;
			int cost = v[j].second;

			if (d[from] == INF || d[to] <= d[from] + cost) continue;

			d[to] = d[from] + cost;
		}
	}

	for (int i = 0; i < M; i++) {
		int from = v[i].first.first;
		int to = v[i].first.second;
		int cost = v[i].second;

		if (d[from] == INF) continue;
		if (d[to] > d[from] + cost) {
			cout << -1;
			return;
		}
	}

	for (int i = 2; i <= N; i++) {
		if (d[i] == INF) d[i] = -1;
		cout << d[i] << "\n";
	}
}

int main(){
	ios_base::sync_with_stdio(false);
	cin.tie(NULL); cout.tie(NULL);

	cin >> N >> M;

	int a, b, c;
	for (int i = 0; i < M; i++) {
		cin >> a >> b >> c;
		v.push_back({ {a, b},c });
	}

	solution();
	
	return 0;
}
```
