### 어떤 문제인가

캐시 크기와 도시 이름 목록이 주어질 때, **LRU 방식으로 캐시를 운영했을 때의 총 실행시간**을 구하는 문제다.

- cache hit이면 1, cache miss면 5가 더해진다
- 도시 이름은 대소문자를 구분하지 않는다
- 캐시 크기는 0 이상 30 이하, 도시는 최대 100,000개

<br/>

### LRU가 핵심

LRU 알고리즘에 대해 알고 있다면 쉽게 문제를 해결할 수 있다.
LRU(Least Recently Used)는 페이지 교체 알고리즘의 일종으로, **가장 오랫동안 참조되지 않은 항목을 교체**하는 기법이다. 이번 문제의 핵심이다.

주의할 건 "가장 오래 전에 들어온 것"이 아니라 "가장 오래 전에 **쓰인** 것"이라는 점이다.
그래서 캐시에 이미 있는 값을 다시 참조해도(hit) 그 값을 가장 최근 위치로 **옮겨줘야** 한다. 이 갱신을 빼먹으면 LRU가 아니라 FIFO가 된다.

<br/>

### 왜 queue가 아니라 deque인가

나는 이러한 방식을 `queue`를 이용하여 해결하려고 했었다.
그러나 큐를 이용하게 되면 **중간에 위치한 값들에 접근하기가 쉽지 않아**, 큐보다 쉽게 값에 접근할 수 있는 `deque`를 이용하였다.

`queue`는 앞에서 빼고 뒤에서 넣는 것만 되는데, LRU는 hit이 났을 때 **중간에 있는 값을 꺼내 맨 앞으로 옮기는** 동작이 필요하다.
`deque`는 인덱스로 접근할 수 있고 양쪽 끝에서 삽입·삭제가 되므로 이 동작이 자연스럽게 표현된다.

정리하면 이렇게 동작한다.

- **hit** — 해당 위치에서 지우고 `push_front`. 실행시간 +1
- **miss & 여유 있음** — `push_front`. 실행시간 +5
- **miss & 가득 참** — `pop_back`(가장 오래 안 쓰인 것 제거) 후 `push_front`. 실행시간 +5

<br/>

### 접근 방식

우선 모든 대문자를 소문자로 바꾸어 구분을 없애주고, `cacheSize` 크기의 `deque`에 차례대로 값을 넣으면서 LRU 방식에 맞게 교체해주었다.
값이 이미 있으면 cache hit이므로 `answer += 1`, 없으면 cache miss이므로 `answer += 5`를 해주면서 실행시간을 구해냈다.

```c++
transform(elem.begin(), elem.end(), elem.begin(), ::tolower);
```

대소문자를 구분하지 않는다는 조건 때문에 비교 전에 전부 소문자로 맞춘다.
이 처리를 빼먹으면 "Jeju"와 "JEJU"를 다른 도시로 세게 되어 답이 틀린다.

<br/>

### 캐시 크기가 0인 경우

```c++
if (cacheSize == 0) return cities.size() * 5;
```

`cacheSize`가 0이면 아무것도 담기지 않으므로 전부 miss다. 도시 수 × 5를 바로 돌려주면 된다.
이 처리를 안 하면 `cacheSize == dq.size()`가 `0 == 0`으로 참이 되면서 빈 `deque`에 `pop_back()`을 호출하게 되어 정의되지 않은 동작에 빠진다.

<br/>

### 시간 복잡도

도시 하나마다 `deque` 안을 선형으로 탐색하므로 **O(도시 수 × 캐시 크기)** 다.
캐시 크기가 최대 30으로 작아서 100,000 × 30 = 300만 번 정도이고, 제한 안에 충분히 들어온다.

캐시가 훨씬 컸다면 `unordered_map`으로 위치를 O(1)에 찾고 연결 리스트로 순서를 관리하는, 실제 LRU 캐시 구현 방식이 필요했을 것이다.

<br/>

### 풀이 코드

```c++
#include <deque>
#include <algorithm>

using namespace std;

int solution(int cacheSize, vector<string> cities) {
    int answer = 0;
    deque<string> dq;

    if (cacheSize == 0) return cities.size() * 5;
    for (auto elem : cities) {
        transform(elem.begin(), elem.end(), elem.begin(), ::tolower);
        bool tf = false;
        int i;
        for (i = 0; i < dq.size(); ++i)
            if (elem == dq[i]) {
                tf = true;
                break;
            }
        if (tf) {
            dq.erase(dq.begin() + i);
            dq.push_front(elem);
            answer += 1;
        }
        else {
            if (cacheSize == dq.size()) dq.pop_back();
            dq.push_front(elem);
            answer += 5;
        }
    }

    return answer;
}
```

`for (auto elem : cities)`가 값 복사인 것이 여기서는 오히려 편했다.
`elem`을 소문자로 바꿔도 원본 `cities`는 그대로라 부작용이 없다. 참조(`auto&`)로 받았다면 입력을 훼손하게 된다.
