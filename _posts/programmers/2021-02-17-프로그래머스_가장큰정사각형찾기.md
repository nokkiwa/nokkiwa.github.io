### 어떤 문제인가

0과 1로 채워진 2차원 표에서, **1로만 이루어진 가장 큰 정사각형의 넓이**를 구하는 문제다.
표의 행과 열은 각각 최대 1,000이다.

<br/>

### 왜 완전 탐색으로는 안 되나

가장 먼저 떠오르는 건 모든 칸을 시작점으로 두고 정사각형 크기를 하나씩 키워보는 방법이다.
그런데 1,000 × 1,000이면 칸이 100만 개이고, 각 칸마다 최대 1,000까지 크기를 키우며 내부를 다 확인하면 연산량이 감당이 안 된다.

그래서 **이미 계산한 결과를 재사용하는 DP**로 접근했다.

<br/>

### 접근 방식

이 문제는 DP를 이용하여 해결하였다.
`board[1][1]`부터 반복을 시작하여 **위, 왼쪽, 왼쪽 대각선** 세 칸과 비교해 (가장 작은 수 + 1)을 그 칸의 값으로 바꾸어준다.
이때의 값이 바로 그 칸을 **오른쪽 아래 꼭짓점으로 하는** 정사각형의 한 변의 길이가 된다.

이 과정을 반복하면서 한 변의 최댓값을 `answer`에 저장해 두면, 마지막에 `answer * answer`가 최대 넓이가 된다.

핵심 코드는 이 부분이다.

```c++
board[i][j] = min({board[i-1][j-1], board[i-1][j], board[i][j-1]}) + 1;
```

**왜 세 칸의 최솟값인가.**
어떤 칸을 오른쪽 아래 꼭짓점으로 하는 한 변 3짜리 정사각형이 성립하려면, 그 칸의 왼쪽·위·왼쪽위를 꼭짓점으로 하는 한 변 2짜리 정사각형이 **셋 다** 있어야 한다.
셋 중 하나라도 작으면 그만큼밖에 못 만든다. 그래서 최솟값을 따르고, 자기 자신 한 칸을 더해 +1을 한다.

예를 들어 세 칸이 각각 2, 2, 1이면 최솟값이 1이므로 이 칸에서 만들 수 있는 정사각형은 한 변 2까지다.

<br/>

### 시간 복잡도

각 칸을 한 번씩만 보므로 **O(행 × 열)**, 최대 100만 번이다.
완전 탐색과 달리 칸마다 상수 시간(세 칸 비교)만 쓰기 때문에 제한 안에 들어온다.

<br/>

### 풀이 코드

```c++
#include <vector>
#include <algorithm>
using namespace std;

int solution(vector<vector<int>> board)
{
    int answer = 0;
    
    if(board.size()<2 || board[0].size()<2){
        return 1;
    }
    
    for(int i=1;i<board.size();++i)
        for(int j=1;j<board[0].size();++j)
            if(board[i][j]==1){
                board[i][j] = min({board[i-1][j-1], board[i-1][j] , board[i][j-1]})+1;
                answer = max(answer,board[i][j]);
            }

    return answer*answer;
}
```

`min({a, b, c})`는 C++11부터 쓸 수 있는 initializer_list 버전이다. `min(a, min(b, c))`로 중첩해서 쓰지 않아도 된다.

<br/>

### 놓치기 쉬운 부분

**첫 행과 첫 열을 건드리지 않는 이유**는 위나 왼쪽에 볼 칸이 없기 때문이다.
그 칸들의 값은 원래 값(0 또는 1)이 그대로 정답이므로 갱신할 필요가 없다.

대신 그래서 **표가 1행이거나 1열인 경우**에는 반복문이 한 번도 돌지 않아 `answer`가 0으로 남는다.
이 예외를 앞에서 따로 처리해 준 것이 이 부분이다.

```c++
if(board.size()<2 || board[0].size()<2){
    return 1;
}
```

다만 이 처리는 표에 1이 하나라도 있다는 전제를 깔고 있다. 1행이면서 전부 0인 표가 들어오면 0이 아니라 1을 돌려주게 된다.
문제의 테스트는 통과했지만, 엄밀하게는 그 행에 1이 있는지 확인해서 `return`값을 정하는 쪽이 맞다.

**입력 배열을 그대로 고쳐 쓰는 것**도 짚어둘 만하다.
`board`를 값으로 받았기 때문에 원본에는 영향이 없지만, 참조로 받았다면 호출한 쪽의 데이터가 바뀐다. DP 테이블을 따로 만드는 편이 안전할 때가 많다.
