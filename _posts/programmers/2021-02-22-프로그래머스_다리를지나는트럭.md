### 어떤 문제인가

일 차선 다리를 트럭들이 정해진 순서대로 건널 때, **모든 트럭이 다 건너는 데 걸리는 최소 시간**을 구하는 문제다.

- 트럭은 1초에 1만큼 움직이고, 다리 길이는 `bridge_length`
- 다리는 무게 `weight`까지 견딘다
- 다리에 완전히 오르지 않은 트럭의 무게는 세지 않는다

다리 길이, 무게, 트럭 수 모두 최대 10,000이다.

<br/>

### 시뮬레이션 문제다

계산식으로 한 번에 구하는 게 아니라, **1초씩 시간을 흘려보내며 상태를 갱신**하는 유형이다.
다리 위에 무엇이 올라가 있고 각각 얼마나 남았는지를 관리하면 된다.

다리는 일 차선이라 먼저 올라간 트럭이 먼저 내려온다. 그래서 큐가 자연스럽게 맞는 자료구조다.

<br/>

### 접근 방식

다리 위에 올라가 있는 트럭을 큐를 이용하여 구현하였다. 변수는 이렇다.

- `sum` — 현재 다리 위의 트럭들의 무게 합
- `now` — 현재 다리 위에 올라와 있는 트럭들
- `length` — 다리 위에 올라와 있는 트럭들의 남은 거리

매 초마다 하는 일은 세 가지다.

**1. 다리 위 트럭들을 한 칸씩 전진시킨다.**
남은 거리가 1이던 트럭은 이번 초에 다리를 벗어나므로 큐에서 빼고 `sum`에서 무게를 뺀다.

```c++
int size = length.size();
for(int i=0;i<size;++i){
    int l = length.front();
    length.pop();
    if(l==1){
        sum -= now.front();
        now.pop();
        continue;
    }
    length.push(l-1);
}
```

여기서 `int size = length.size()`를 **미리 저장해 두는 게 중요하다.**
반복문 안에서 `push`를 하기 때문에, 조건식에 `length.size()`를 직접 쓰면 크기가 계속 늘어나 같은 트럭을 여러 번 전진시키게 된다.

**2. 다음 트럭을 올릴 수 있으면 올린다.**
현재 무게 합에 다음 트럭 무게를 더해도 `weight`를 넘지 않을 때만 올린다.

**3. 시간을 1 증가시킨다.**

이 과정을 반복하다가 대기 중인 트럭도, 다리 위 트럭도 없어지면 멈추고 그때의 `answer`가 최소 시간이 된다.

<br/>

### 종료 조건의 위치

```c++
++answer;

if(truck_weights.empty() && now.empty())
    break;
```

`++answer`를 먼저 하고 종료를 확인한다.
마지막 트럭이 다리를 벗어나는 그 순간도 1초로 세야 하기 때문이다. 순서를 바꾸면 답이 1 적게 나온다.

<br/>

### 시간 복잡도

전체 반복 횟수는 대략 **O(트럭 수 × 다리 길이)** 이고, 여기에 매 초 다리 위 트럭을 훑는 비용이 붙는다.
제한(각 10,000)에서는 통과했지만 여유가 많은 편은 아니다.

`truck_weights.erase(truck_weights.begin())`가 특히 비싼 부분이다.
`vector`의 맨 앞 원소를 지우면 뒤의 원소를 전부 앞으로 당기므로 **O(n)** 이 든다. 트럭 목록도 `queue`나 인덱스로 관리했다면 이 비용을 없앨 수 있었다.

<br/>

### 풀이 코드

```c++
#include <string>
#include <vector>
#include <queue>

using namespace std;

int solution(int bridge_length, int weight, vector<int> truck_weights) {
    int answer = 0, sum = 0;
    queue<int> now, length;
    
    while(1){
        int size = length.size();
        for(int i=0;i<size;++i){
            int l = length.front();
            length.pop();
            if(l==1){
                sum -= now.front();
                now.pop();
                continue;
            }
            length.push(l-1);
        }
        
        if(truck_weights.size()>0 && sum+truck_weights[0]<=weight){
            sum += truck_weights[0];
            now.push(truck_weights[0]);
            length.push(bridge_length);
            truck_weights.erase(truck_weights.begin());
        }
        
        ++answer;
        
        if(truck_weights.empty() && now.empty())
            break;
    }

    return answer;
}
```

### 더 줄일 수 있는 부분

지금은 트럭 목록과 남은 거리를 큐 두 개로 나눠 관리하는데, `pair`를 담은 큐 하나로 합치면 두 큐의 인덱스가 어긋날 걱정이 없다.
다리 길이만큼의 큐를 만들고 0을 채워 넣는(빈 칸을 0으로 표현하는) 방식으로 풀면 코드가 더 짧아지기도 한다.
