### 어떤 문제인가

1, 2, 4 세 개의 숫자만으로 모든 자연수를 표현하는 체계가 있다고 할 때, 주어진 십진수 `n`을 그 표현으로 바꾸는 문제다.
n은 5억 이하의 자연수다.

말하자면 **0이 없는 3진법**이다. 일반 3진법은 0, 1, 2를 쓰는데 여기서는 1, 2, 4를 쓴다.

<br/>

### 접근 방식

124를 일종의 3진법으로 생각하여 문제를 접근하였다.
`while`문 내에서 n을 3으로 나누면서 나머지 1, 2, 0을 각각 1, 2, 4에 대응시켜 `answer`에 `push_back` 해준 뒤, `reverse` 함수로 앞뒤를 바꿔주었다.

여기서 핵심은 **나머지가 0일 때의 처리**다.

```
n % 3 == 1  →  '1',  n /= 3
n % 3 == 2  →  '2',  n /= 3
n % 3 == 0  →  '4',  n = n/3 - 1
```

앞의 두 경우는 일반 진법 변환과 똑같은데, 나머지가 0인 경우만 `n/3`이 아니라 **`n/3 - 1`** 을 해준다.

이 부분이 처음에 막혔던 지점이라 왜 그런지 따로 정리해 둔다.
일반 3진법에서 나머지 0은 자릿수 0을 뜻하지만, 이 체계에는 0이 없다. 나머지가 0이면 3의 배수라는 뜻이고, 그 자리에 4를 쓴다.
4를 쓴다는 건 **3을 한 번 빌려 쓴 것**이므로, 윗자리에서 1을 빼줘야 계산이 맞는다.

예를 들어 n = 3일 때, 나머지가 0이므로 '4'를 쓰고 `n = 3/3 - 1 = 0`이 되어 반복이 끝난다. 결과는 "4"다.
`-1`이 없었다면 `n = 1`이 남아서 "14"라는 틀린 답이 나온다.

<br/>

### 시간 복잡도

n을 매 반복마다 3으로 나누므로 자릿수만큼만 돈다. **O(log₃ n)** 이다.
n이 5억이어도 반복은 19번 정도라 여유롭다.

<br/>

### 풀이 코드

```c++
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

string solution(int n) {
    string answer = "";
    int r;

    while (n > 0) {
        r = n % 3;
        if (r == 0) {
            answer.push_back('4');
            n = n/3 - 1;
        }
        else if (r == 1) {
            answer.push_back('1');
            n /= 3;
        }
        else {
            answer.push_back('2');
            n /= 3;
        }
    }

    reverse(answer.begin(), answer.end());

    return answer;
}
```

낮은 자리부터 구해지므로 마지막에 `reverse`로 뒤집는다.
앞에서부터 만들려고 `answer = c + answer` 같은 식으로 붙이면 문자열을 매번 새로 만들게 되어 더 느리다.

<br/>

### 배운 점

진법 변환 문제인데 **0이 없다**는 조건 하나가 붙으면 계산이 달라진다는 걸 알게 됐다.
비슷한 유형(예: 엑셀 열 이름 A~Z를 숫자로 바꾸기)에서도 같은 방식의 보정이 필요하다.
