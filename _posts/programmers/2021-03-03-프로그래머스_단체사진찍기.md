### 어떤 문제인가

8명이 일렬로 서서 사진을 찍는데, 각자 "누구와 몇 칸 떨어져 서고 싶다"는 조건을 제시한다.
**모든 조건을 만족하는 배치가 몇 가지인지** 세는 문제다.

조건은 `N~F=0` 같은 다섯 글자 문자열로 주어진다.

- 1번째 글자: 조건을 낸 사람
- 3번째 글자: 상대방
- 4번째 글자: `=`, `<`, `>` 중 하나
- 5번째 글자: 간격 (0~6)

여기서 **간격은 두 사람 사이에 있는 다른 사람의 수**다. 자리 인덱스 차이가 아니라는 게 중요하다.

<br/>

### 입력 형식에서 얻는 정보

이 문제는 입력 형식을 자세히 봐야 실수를 안 할 수 있다.
문제 본문에는 명시되어 있지 않지만, **서는 인원이 총 8명**이라는 것과 비교 연산자가 세 종류뿐이라는 것을 입력 형식에서 읽어낼 수 있다.

8명이면 가능한 배치는 8! = 40,320가지다. 전부 만들어 확인해도 충분한 규모라 **완전 탐색(순열)** 으로 접근했다.
같은 사람이 두 번 설 수는 없으므로 조합이 아니라 순열이다.

<br/>

### 접근 방식

문자열 `"ACFJMNRT"`의 모든 순열을 만드는 함수를 작성하고, 만들어진 배치가 `data`의 조건을 모두 만족하면 `++answer`를 해주었다.

순열은 **swap 후 재귀, 그리고 다시 swap으로 되돌리는** 백트래킹 방식으로 만들었다.

```c++
for (int i = start; i <= end; ++i) {
    swap(friends[start], friends[i]);
    stringFriends(friends, start + 1, end, data, answer);
    swap(friends[start], friends[i]);   // 원상 복구
}
```

두 번째 `swap`이 빠지면 다음 반복이 오염된 상태에서 시작해 배치가 중복되거나 누락된다.

<br/>

### 간격 계산에서 -1을 하는 이유

```c++
int distance = friends.find(d[0]) - friends.find(d[2]);
int num = d[4] - '0';
...
if (abs(distance) - 1 == num) tf = true;
```

`find`로 두 사람의 자리 인덱스를 구해 차이를 낸 뒤, **절댓값에서 1을 뺀다.**

인접해 있으면 인덱스 차이는 1인데 사이에 낀 사람은 0명이다. 문제에서 말하는 간격은 후자이므로 1을 빼야 맞는다.
`abs`를 쓰는 건 누가 왼쪽인지 오른쪽인지는 상관이 없기 때문이다.

이 `-1`을 빠뜨리면 모든 조건이 한 칸씩 밀려서 답이 전부 틀린다. 이 문제에서 가장 많이 실수하는 지점이라고 생각한다.

<br/>

### 시간 복잡도

순열 8! = 40,320개를 만들고, 각 배치마다 조건 최대 100개를 확인한다.
조건 하나를 볼 때 `find`가 문자열을 훑으므로 상수에 가까운 비용이 붙어, 전체 **400만 번** 정도다. 제한 안에 들어온다.

<br/>

### 풀이 코드

```c++
#include <string>
#include <vector>
#include <cstdlib>

using namespace std;

void stringFriends(string& friends, int start, int end, vector<string>& data, int& answer) {
    if (start == end) {
        bool tf = false;
        for (auto d : data) {
            int distance = friends.find(d[0]) - friends.find(d[2]);
            int num = d[4] - '0';

            switch (d[3]) {
            case '=':
                if (abs(distance) - 1 == num) tf = true;
                else tf = false;
                break;
            case '<':
                if (abs(distance) - 1 < num) tf = true;
                else tf = false;
                break;
            case '>':
                if (abs(distance) - 1 > num) tf = true;
                else tf = false;
                break;
            }
            if (!tf) break;
        }
        if (tf) ++answer;
    }
    else {
        for (int i = start; i <= end; ++i) {
            swap(friends[start], friends[i]);
            stringFriends(friends, start + 1, end, data, answer);
            swap(friends[start], friends[i]);
        }
    }
}

int solution(int n, vector<string> data) {
    int answer = 0;
    string friends = "ACFJMNRT";
    
    stringFriends(friends, 0, friends.size() - 1, data, answer);

    return answer;
}
```

### 풀고 나서 알게 된 것

다른 분들의 풀이를 보고 두 가지를 배웠다.

**1. 조건 검사는 bool 함수로 빼는 게 낫다.**
조건을 만족할 때마다 `++cnt`를 하고 마지막에 `if (cnt == data.size())`로 확인하는 방식보다, 조건 하나라도 어긋나면 바로 `return false` 하는 편이 훨씬 빠르다.
40,320개 배치 × 조건 100개를 전부 도는 것과, 대부분 첫 조건에서 걸러지는 것의 차이다.

**2. 순열은 직접 만들 필요가 없다.**
`algorithm` 라이브러리의 [next_permutation](http://www.cplusplus.com/reference/algorithm/next_permutation/)을 쓰면 재귀 함수 없이 순열을 순회할 수 있다.

```c++
string friends = "ACFJMNRT";   // 반드시 정렬된 상태에서 시작
do {
    if (check(friends, data)) ++answer;
} while (next_permutation(friends.begin(), friends.end()));
```

단 `next_permutation`은 **사전순으로 다음 순열**을 만들기 때문에 시작 문자열이 정렬되어 있어야 전부 순회한다.
`"ACFJMNRT"`는 이미 알파벳 순이라 그대로 쓸 수 있다.
